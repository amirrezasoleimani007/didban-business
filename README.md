# دیدبان کسب‌وکار آتیه

نسخه ۱.۱ — داشبورد فارسی رصد بازار فولاد و فضای کسب‌وکار داخلی و جهانی.

اجرای آنلاین فعلی: https://didban-business-soleimani.amirreza-soleimani11.chatgpt.site

## اجرا

فایل index.html را در نسخه جدید Chrome یا Edge باز کنید. نصب کتابخانه لازم نیست. فونت وزیرمتن و داده اولیه همراه برنامه هستند.

## به‌روزرسانی داده

در برنامه «ورود اکسل» را انتخاب کنید. نام فایل آزاد است. ستون‌های Date، Indicator، Unit، Value و تواتر و نام شیت‌های اصلی باید حفظ شوند. داده‌ها در مرورگر پردازش و ذخیره می‌شوند. فایل جدید مجموعه داده فعال را جایگزین می‌کند.

## ساختار

- index.html: پوسته برنامه و صفحه ورودی
- app.js: خواندن XLSX، کنترل کیفیت، محاسبات و نمودارها
- visuals.js و experience.js: آیکون‌ها و تعامل‌های ورودی
- style.css و experience.css: ظاهر و پویانمایی
- data.js: داده اولیه استخراج‌شده از فایل اکسل
- vazirmatn-*.ttf و OFL.txt: فونت وزیرمتن و مجوز آن
- atieh-logo.png: لوگوی ارائه‌شده آتیه

## انتشار روی GitHub Pages

این پروژه یک سایت ایستا است. پس از بارگذاری در مخزن، در Settings → Pages، انتشار از شاخه اصلی و پوشه root را انتخاب کنید؛ در صورت پشتیبانی حساب و تنظیمات مخزن، GitHub لینک منتشرشده را نمایش می‌دهد. به مرحله build نیازی نیست.

## محاسبات و نمایش

اعداد برای نمایش بدون اعشار گرد می‌شوند؛ محاسبات با دقت کامل انجام می‌شوند. تغییر شامخ با واحد شاخص و تورم با واحد درصد نمایش داده می‌شود. تاریخ‌های متناقض از محاسبات کنار گذاشته می‌شوند و تکرار یکسان حذف می‌شود. در داده روزانه، آخرین مشاهده پیش از تاریخ هدف با حداکثر فاصله ۱۴ روز و در داده ماهانه و فصلی، ماه متناظر مبناست.

## منابع و مجوز

داده و لوگو متعلق به منبع ارائه‌شده توسط مالک پروژه هستند. برای این پروژه مجوز متن‌باز اعلام نشده است. مجوز فونت در OFL.txt قرار دارد.
